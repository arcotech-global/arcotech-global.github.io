# ARCOTECH · 元核科技

Corporate website of Arcotech (Tianjin) Co., Ltd. Static site served by GitHub Pages at https://arcotech-global.github.io

Languages: `/` 中文 · `/en/` · `/pt/` · `/es/` · `/fr/` · `/no/` · `/ja/` · `/ko/`

To use a custom domain (e.g. www.arcotech.cn): add a `CNAME` file containing the domain, set a DNS CNAME record pointing to `arcotech-global.github.io`, then replace the base URL in each `index.html`, `robots.txt` and `sitemap.xml`.
